# Markdeck

Mac 桌面文档工具：直接点击排版后的正文编辑，打开本地 Markdown 后，修改自动写回原文件。没有编辑／预览模式切换。段首输入 `- `、`* `、`+ ` 自动创建无序列表，输入 `1. ` 等数字加点和空格自动创建有序列表；转换后按退格可以恢复原字符。

## 使用

打开 `release/Markdeck-darwin-arm64/Markdeck.app`（Apple Silicon Mac）。启动时默认最大化，铺满屏幕可用区域；绿色窗口按钮可进入 macOS 全屏。点击「打开」选择 `.md`、`.markdown` 或 UTF-8 `.txt` 文件，然后直接修改文字、标题、列表、表格。顶部「已保存到文件」表示原文件已写入。

新文档先自动存为应用草稿；点击「保存到文件」选择位置后，后续修改自动写回。标题栏里的文档名称是应用内名称，修改名称不会重命名磁盘文件。Markdown 文件保存正文内容，不会额外插入重复标题。

文件被其他软件修改时，应用保留草稿并停止覆盖，显示「文件未写回」。可以「另存为」保留自己的版本，或「刷新」采用磁盘版本。原文件被移动、删除或无法写入时也会保留草稿。关闭窗口会等待保存；保存不完整时会提示。

从文档列表移除文档不会删除已关联的磁盘文件。应用内草稿和文件关联保存在 macOS 用户应用数据目录下的 `workspace.json`（为兼容旧版，仍使用 `~/Library/Application Support/云笺/`；改名不会清空草稿、文件关联或界面偏好）。Web 版浏览器中的旧文档不会自动出现在桌面版，需先导出 Markdown 再打开。

Claude 等外部工具修改当前文件后，Markdeck 每 1.5 秒检查一次，在没有冲突时自动更新正文和目录；回到应用窗口时也会检查。顶部刷新图标（⌘R）仍可手动重新读取。未关联文件的草稿不能刷新；如果有未写回的修改，会先确认是否放弃。

快捷键：⌘N 新建、⌘O 打开、⌘S 保存、⇧⌘S 另存为、⌘R 刷新、⌘K 搜索、⌘B 加粗。支持左侧目录、标题实时更新和滚动高亮，文档列表按需展开。顶部设置图标集中管理皮肤、正文大小、目录和格式工具栏显示，另存为和收藏也在这里。皮肤提供「经典白」「黑底绿字」（低饱和灰绿正文、浅绿标题和重点）「浅绿底黑字」，选择后立即切换并在应用重启后保留；不会修改 Markdown 文件。

既有文件只打开、不编辑时保持原文件字节；修改后由编辑器序列化为 Markdown，空行、表格分隔符等源码格式可能规范化。已关联文件保留 UTF-8 BOM 和 CRLF 换行；仅支持 UTF-8、不超过 10 MB 的文本文件。外部修改会在下次保存或应用重新启动时检查，目前不包含多设备云同步或多人协作；自动更新只检查当前打开的文档，出现冲突时保留草稿并停止覆盖。

## 开发与打包

```sh
npm install
npx install-electron
npm start
npm run package:mac
```

Electron 当前版本的二进制需要通过 `install-electron` 下载；`npm start` 构建界面并启动桌面窗口，`package:mac` 输出 Mac arm64 `.app`。当前应用包已做本地临时签名（ad-hoc），尚未配置 Developer ID 签名和公证。

```sh
npm run test:files
npm run test:shortcuts
npm run test:desktop
```

文件检查覆盖原路径写回、BOM/CRLF、草稿恢复、外部冲突、另存为、缺失文件、不可信路径与损坏存储保护。桌面检查通过真实 Electron 窗口验证正文和表格编辑、文件自动保存、重启恢复和冲突处理。需要运行环境允许启动桌面进程。

`npm run dev` 仍可预览 Web 界面；Web 模式只保存到浏览器，不会自动写回电脑文件。`npm test` 为 Web 浏览器检查（先启动开发服务）。

使用 TOAST UI Editor 处理选区、撤销和 Markdown 转换，Electron 主进程管理文件读写。正文进程关闭 Node 集成并启用上下文隔离和沙箱，只通过有限接口操作用户选择过的文件。

本次验证：10 项文件测试和生产构建通过；应用包资源与本地签名校验通过。当前受限环境启动 Electron 时会终止进程，桌面端到端测试未能执行完成。

品牌色为绿色 `#2b7d53`。图标源文件为 `desktop/icon.svg`，原生渲染脚本为 `desktop/render-icon.swift`；应用包使用多尺寸 `desktop/icon.icns`。

输入规则另有 4 项检查，覆盖无序和有序列表、段中符号和代码块排除、转换撤销。

## 展示模式

设置或文件菜单选择「进入展示模式」。展示原 Markdown 文档，隐藏工具栏、导航和元信息，并扩大字号、调整内容宽度。展示期间正文只读，按 Esc 或点击右下角退出后恢复直接编辑。展示模式不修改正文。旧 PPT 确认稿入口已撤下，历史稿件和相关文件保留。

应用名为 Markdeck，保留原云笺数据目录和应用标识，以兼容已有文档和配置。新版位于 `release/Markdeck-darwin-arm64/Markdeck.app`。

## 查找、历史与交付

设置里提供查找替换（⌘F／⌘H）、修改记录与恢复、HTML／PDF 导出。正文替换通过编辑器事务完成，可撤销；目录可搜索和折叠子章节。历史保存于应用数据目录 `history/`，普通编辑每分钟最多留一个快照，外部更新和恢复前额外留存；每份文档最多 30 个版本、约 20 MB。记录从升级后的修改开始，不含此前所有历史。对比显示旧内容与当前内容的变化行，恢复会保存当前版本并检查外部文件是否又有修改。

HTML 内嵌样式与图片，离线打开无需安装应用；PDF 通过 Electron 打印为 A4，打印时使用浅色配色。不能读取或跨域打包的图片会提示，而非静默忽略。真实打印分页仍需在桌面环境验证。

已关联文件的新图片写入同目录的 `文档名.assets/`，使用相对链接；未关联文件的草稿仍内嵌图片。另存到不同目录时复制已引用的附件，分享 Markdown 时需同时携带附件目录，HTML／PDF 导出自动嵌入。图片操作条支持图左文右、图右文左和并排；标题和表格清除图文环绕。展示工具可跳章节、全屏和临时高亮选中文字；高亮不写入文档，退出后清除。

整体检查：`node tests/app-flow.mjs`、`node tests/history-find.mjs`、`node tests/document-export.mjs`、`node tests/attachments.cjs`、`node tests/display-mode.mjs`、`node tests/image-controls.mjs`、`node tests/compress-image.mjs`、`node tests/table-controls.mjs`、`npm run test:files`、`npm run test:shortcuts`。DOM 检查不等于真实窗口视觉或实际 PDF 打印验证。

## 文档逻辑面板

设置 → 文档逻辑面板。根据正文标题自动显示横向阅读主线和纵向章节分支，支持主线／分支／全部层级、收起展开、缩放、拖动画布以及点击节点跳回正文。单一文档标题作为面板标题，使用下一层章节作为主线。连线仅表示文档顺序与标题层级，不表示系统推断的因果或依赖；不会改写文档。检查：`node tests/logic-panel.mjs`。
